# Security Statement

**COSMIC SHIELD (PTY) LTD** uses commercially reasonable technical and organisational measures to protect personal information and website data.

## Security Measures

These measures include:

- Secure hosting
- HTTPS encryption
- Access controls
- Firewall protection
- Regular updates and monitoring
- Backups
- Authentication controls for admin accounts
- Multi-factor authentication for sensitive operations

## Limitations

No system can be guaranteed completely secure. We therefore cannot guarantee absolute immunity against cyber threats, but we take reasonable steps to reduce the risk of unauthorised access, misuse, or disclosure.

## Reporting Security Issues

If you discover a security vulnerability, please report it to:

**Email:** support@cosmicshield.co.za

We take all security reports seriously and will investigate promptly.
